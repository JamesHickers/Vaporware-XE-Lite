## <img src="https://cdn.simpleicons.org/github" width="24" alt="GitHub"> What Happened?

**VaporWareXE Lite v4 was the final version of the project.**

The original Vaporware project was later moved away from GitHub. The original project holders left GitHub without notifying everyone, and the GitHub copy was subsequently removed.

Vaporware was then **moved and replaced by a different project: NiggaHub**.

NiggaHub is the current successor to the Vaporware project and has since moved from GitHub to Codeberg.

### <img src="https://cdn.simpleicons.org/codeberg" width="20" alt="Codeberg"> NiggaHub

**NiggaHub** is the current successor and replacement for Vaporware.

It is a broad digital-resource hub covering software, services, websites, privacy, security, operating systems, Linux, Windows, Android, networking, self-hosting, development, AI, gaming, media, and other digital resources.

The project is **continuously changing and expanding**.

> [!IMPORTANT]
> NiggaHub's contents are intentionally **not listed in this README**.
>
> The collection changes over time, with resources being added, removed, replaced, reorganized, or updated. The live NiggaHub repository should therefore be treated as the current source of truth.

## <img src="https://cdn.simpleicons.org/git" width="24" alt="Git"> Why This Fork Exists

This repository exists to preserve **VaporWareXE Lite v4** and document what happened to the project after its move away from GitHub.

The fork provides a clear reference for people who encounter the old VaporWareXE Lite project and need to know:

* That **v4 was the final version**
* That this is an **official fork**
* That **only the README was changed**
* That the original project moved away from GitHub
* That Vaporware was **replaced by NiggaHub**
* Where the current successor can be found

This is **not a new VaporWareXE Lite release**.

## <img src="https://cdn.simpleicons.org/refreshcw" width="24" alt="Updates"> Why There Is No Static NiggaHub List

NiggaHub is an actively changing project rather than a frozen snapshot.

Its collection can change when:

* <img src="https://cdn.simpleicons.org/plus" width="16" alt="Added"> New resources are added
* <img src="https://cdn.simpleicons.org/refreshcw" width="16" alt="Updated"> Existing resources are updated
* <img src="https://cdn.simpleicons.org/replace" width="16" alt="Replaced"> Resources are replaced
* <img src="https://cdn.simpleicons.org/link" width="16" alt="Links"> Links change or become unavailable
* <img src="https://cdn.simpleicons.org/trash2" width="16" alt="Removed"> Outdated resources are removed
* <img src="https://cdn.simpleicons.org/folder" width="16" alt="Categories"> Categories evolve
* <img src="https://cdn.simpleicons.org/sparkles" width="16" alt="New"> New types of resources are introduced

For that reason, this README deliberately avoids maintaining a giant static inventory.

**Use the live NiggaHub repository for its current contents.**
