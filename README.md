## <img src="https://cdn.simpleicons.org/github" width="24" height="24" alt="GitHub"> What Happened?

**VaporWareXE Lite v4 was the final version of the project.**

The original Vaporware project was subsequently moved away from GitHub. The original project holders left GitHub without notifying everyone, and the GitHub copy was eventually removed.

The project itself was not simply abandoned. It continued through other repository locations and was ultimately **moved and replaced by a different project: NiggaHub**.

### <img src="https://cdn.simpleicons.org/codeberg" width="24" height="24" alt="Codeberg"> Current Project

[![NiggaHub](https://img.shields.io/badge/NiggaHub-current%20successor-2185d0?style=for-the-badge\&logo=codeberg\&logoColor=white)](https://codeberg.org/7zippy/niggahub)

**NiggaHub** is the current successor and replacement for Vaporware.

It is a broad digital-resource hub covering areas such as:

* Software and applications
* Websites and online services
* Privacy and security
* Operating systems and Linux
* Windows and Android
* Networking and self-hosting
* Development and technical resources
* Artificial intelligence and local AI
* Gaming
* Digital media and entertainment
* File, cloud, and storage resources
* Research and educational resources
* Other digital tools and resources

The collection is **actively changing**, so this README intentionally does **not** contain a static list of everything NiggaHub currently offers.

> [!IMPORTANT]
> **The NiggaHub repository is the source of truth for its current contents.**
>
> Resources may be added, removed, replaced, renamed, or reorganized over time.

## <img src="https://cdn.simpleicons.org/git" width="24" height="24" alt="Git"> Why This Fork Exists

This repository exists primarily as a **historical and informational continuation point** for VaporWareXE Lite.

The original project reached v4, and the project subsequently moved away from GitHub. Since the original GitHub presence disappeared, this fork provides a place where users who still encounter or reference VaporWareXE Lite can understand:

* What happened to the project
* That v4 was the final VaporWareXE Lite version
* That this repository is an official fork
* That only the README was changed here
* Where the project moved
* What replaced Vaporware
* Where the current project can be found

This repository is therefore **not a new software release of VaporWareXE Lite**.

## <img src="https://cdn.simpleicons.org/refreshcw" width="24" height="24" alt="Updates"> Why There Is No Static NiggaHub Resource List

NiggaHub is not intended to be a frozen snapshot.

Its contents can change as:

* New resources are added
* Existing resources are updated
* Resources move to new locations
* Links become obsolete
* Projects disappear
* Better alternatives become available
* Categories evolve
* New technologies and services appear

Because of this, maintaining a large static resource list inside this README would quickly become outdated.

**For the current collection, use the NiggaHub repository directly.**
