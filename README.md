# <img src="https://cdn.simpleicons.org/powershell/5391FE" width="28" height="28" alt="PowerShell"> About

**VaporWareXE Lite** is a lightweight PowerShell-based resource directory.

Choose a category, select a resource, and it opens in your browser. No complicated setup, no large application, and no unnecessary system configuration — just a simple way to find and launch useful resources.

> **VaporWareXE Lite v4 is the final version of the original project.**

This repository is an **official fork of [`VaporwareXE/Vaporware-XE-Lite`](https://github.com/VaporwareXE/Vaporware-XE-Lite)**.

### <img src="https://cdn.simpleicons.org/markdown/000000" width="22" height="22" alt="Markdown"> Important

> [!IMPORTANT]
> **Only `README.md` has been changed in this fork.**
>
> The original PowerShell script and the rest of the project remain unchanged.

This fork exists to preserve the original project and document its move away from GitHub.

# <img src="https://cdn.simpleicons.org/codeberg/2185D0" width="28" height="28" alt="Codeberg"> The Project Moved

The original Vaporware directory has since been **replaced by NiggaHub**.

<p align="center">
  <a href="https://codeberg.org/7zippy/niggahub">
    <img src="https://img.shields.io/badge/NiggaHub-Current%20Project-2185D0?style=for-the-badge&logo=codeberg&logoColor=white" alt="NiggaHub">
  </a>
</p>

**https://codeberg.org/7zippy/niggahub**

NiggaHub is the newer and substantially expanded successor to the original Vaporware directory.

The original Vaporware project focused primarily on security and privacy resources. NiggaHub expands the concept into a much broader digital-resource hub covering software, services, websites, tools, media, games, AI, development, self-hosting, networking, and much more.

```text
VaporWareXE Lite
       │
       │ final release
       ▼
   Vaporware
       │
       │ replaced by
       ▼
   NiggaHub
       │
       ▼
Current expanded resource hub
```

### <img src="https://cdn.simpleicons.org/powershell/5391FE" width="20" alt="PowerShell"> Run directly

```powershell
irm https://raw.githubusercontent.com/VaporwareXE/Vaporware-XE-Lite/refs/heads/main/Vaporware.XE.Lite.ps1 | iex
```

### <img src="https://cdn.simpleicons.org/windows/0078D4" width="20" alt="Windows"> If execution policy blocks the script

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force; irm https://raw.githubusercontent.com/VaporwareXE/Vaporware-XE-Lite/refs/heads/main/Vaporware.XE.Lite.ps1 | iex
```

```powershell
.\VaporWareXE-Lite.ps1
```

> **Prefer to inspect scripts before executing them.** Download the file first if you want to review the source locally.

# <img src="https://cdn.simpleicons.org/security/000000" width="28" height="28" alt="Trust"> Should I Trust This?

The script is open source and can be inspected before execution.

VaporWareXE Lite is intended to function as a **directory and browser launcher**, rather than a system-modification utility.

However, it is still PowerShell code downloaded from the internet.

> [!WARNING]
> **If you don't trust the source, download the script first and review the code before running it.**

# <img src="https://cdn.simpleicons.org/readthedocs/8CA1AF" width="28" height="28" alt="Summary"> In Short

> **VaporWareXE Lite v4 was the final release of the original VaporWareXE Lite project.**

This repository is an **official fork of `VaporwareXE/Vaporware-XE-Lite:main`**.

> [!IMPORTANT]
> **Only `README.md` has been changed.**
>
> The original PowerShell script and the rest of the project remain unchanged.

Vaporware subsequently moved away from GitHub and was **replaced by NiggaHub**, which expanded the original security and privacy directory into a much broader digital-resource hub.
