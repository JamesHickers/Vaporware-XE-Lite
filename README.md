## About

**VaporWareXE Lite** is a lightweight PowerShell-based resource directory.

Choose a category, select a resource, and it opens in your browser. No complicated setup, no large application, and no unnecessary system configuration — just a simple way to find and launch useful resources.

> **VaporWareXE Lite v4 is the final version of the original project.**

This repository is an **official fork of [`VaporwareXE/Vaporware-XE-Lite`](https://github.com/VaporwareXE/Vaporware-XE-Lite)**.

### Important

> **Only `README.md` has been changed in this fork.**
>
> The original PowerShell script and the rest of the project remain unchanged.

This fork exists to preserve the original project and document its move away from GitHub.

## What It Does

|   |                                            |
| - | ------------------------------------------ |
| ✓ | Organizes useful resources into categories |
| ✓ | Opens selected resources in your browser   |
| ✓ | Provides security and privacy resources    |
| ✓ | Displays system information when requested |
| ✓ | Provides a simple PowerShell interface     |

### What It Doesn't Do

* Does not install software
* Does not modify your registry
* Does not change system settings
* Does not require administrator privileges
* Does not collect personal data

# Quick Start

### Run directly

```powershell
irm https://raw.githubusercontent.com/VaporwareXE/Vaporware-XE-Lite/refs/heads/main/Vaporware.XE.Lite.ps1 | iex
```

### If execution policy blocks the script

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force; irm https://raw.githubusercontent.com/VaporwareXE/Vaporware-XE-Lite/refs/heads/main/Vaporware.XE.Lite.ps1 | iex
```

### Or download and run locally

```powershell
.\VaporWareXE-Lite.ps1
```

> **Recommended:** If you don't trust the source, download the script first and review it before executing it.

# Usage

1. Start the script
2. Select a category
3. Select a subcategory
4. Select a resource
5. The resource opens in your browser
6. Press `B` to go back

### Main Menu

| Key | Function           |
| :-: | ------------------ |
| `H` | Help               |
| `S` | System information |
| `B` | Back               |
| `Q` | Quit               |

# Should I Trust This?

The script is open source and can be inspected before execution.

VaporWareXE Lite is intended to function as a **directory and browser launcher**, rather than a system-modification utility.

However, it is still PowerShell code downloaded from the internet.

> **If you don't trust the source, download the script first and review the code before running it.**

# About the Listed Resources

VaporWareXE Lite and NiggaHub are **directories, not certification services**.

A listing does not mean that a resource is guaranteed to be:

* Safe
* Legitimate
* Private
* Free
* Open source
* Appropriate for every user

Resources can be:

* Free or paid
* Open source or proprietary
* Account-based
* Subject to different licenses
* Dependent on additional software
* Governed by their own privacy and security policies

**Research anything you use and review its official documentation before trusting it.**
